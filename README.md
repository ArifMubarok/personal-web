# Personal Website

Arif Rahman Mubarok's personal website — bio, experience, and projects.

Built with [Next.js](https://nextjs.org), React, and [Tailwind CSS](https://tailwindcss.com).

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Content

Site content is sourced from [`docs/personal-web.md`](docs/personal-web.md) and structured in [`src/data/profile.ts`](src/data/profile.ts). Edit `profile.ts` to update the site.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- TypeScript
